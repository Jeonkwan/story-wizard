## 3. Implemented Components & Architectural Details

### 3.1 Workspace Skills (`.agents/skills/`)
- `.agents/skills/gemini-3-8-tts-studio/SKILL.md`: Authoritative reference for Gemini 3.8 models, `@google/genai` initialization, structured JSON prompts, the 8 approved vocal tags, solo narrator style folding, and the 2-speaker ceiling sub-batching rule for cast mode.
- `.agents/skills/gcs-json-catalog/SKILL.md`: Authoritative reference for dual-mode GCS (`ifGenerationMatch`) and `./data/` local filesystem atomic JSON storage, path traversal protection, and HTTP 206/416 partial range streaming.

### 3.2 Canonical Data Contracts (`shared/types.ts`)
`shared/types.ts` defines the shared TypeScript interfaces across the entire pipeline:
- `CatalogItem`: Public & admin catalog schema, tracking status (`draft` | `published`), audio version counts, and default audio URLs.
- `CharacterProfile`: Unique character definitions (`name`, `traits`) excluding `"Narrator"`.
- `ScriptTurn`: Individual story turn (`turn_id`, `speaker`, `style`, `text`).
- `VoiceDesignCandidate`: 1–3 candidate prompts generated by Director LLM for custom voice creation.
- `VoiceCasting`: Configuration for `solo` (single narrator) or `cast` mode (speaker-to-voice mapping).
- `AudioVersion`: Immutable synthesized version slug, duration, casting details, and WAV URL.
- `Story`: Full entity including script turns, voice candidates, and audio version array.
- `VoiceEntry`: Catalog entry for prebuilt (`Kore`, `Puck`, `Aoede`) or designed (`voice_...`) voices.

### 3.3 Text Sanitation Engine (`shared/textClean.ts`)
`shared/textClean.ts` implements:
- `APPROVED_VOCAL_TAGS`: Exact set of 8 approved lowercase tags (`<sigh>`, `<laugh>`, `<chuckle>`, `<gasp>`, `<yawn>`, `<breath>`, `<short pause>`, `<long pause>`).
- `cleanTextForReader(text)`: Regular expression `/<[^>]+>/g` specifically stripping angle-bracket vocal cues while preserving prose in parentheses such as `"(painted bright blue)"`.

### 3.4 Pure Audio Engine (`server/lib/wav.ts`)
`server/lib/wav.ts` performs pure byte-level manipulation without external binaries:
- `SAMPLE_RATE = 24000`, `CHANNELS = 1`, `BITS_PER_SAMPLE = 16`, `BYTES_PER_SECOND = 48000`.
- `extractPcmFromWavOrRaw(input: Buffer)`: Safely walks RIFF chunk headers (`fmt `, `LIST`, `JUNK`, etc.) to locate the `data` chunk and extract raw PCM bytes. Handles raw PCM buffers gracefully if no RIFF header exists.
- `createSilencePcm(durationMs: number)`: Allocates exact zero-byte buffers for padding (e.g., 150ms transition silence = 7,200 bytes).
- `wrapPcmAsWav(pcm: Buffer)`: Prepends a single canonical 44-byte RIFF/WAVE header and calculates duration in seconds (`Math.max(1, Math.round(dataSize / BYTES_PER_SECOND))`).

### 3.5 Deterministic Validators (`server/lib/validators.ts`)
`server/lib/validators.ts` implements the multi-stage validation pipeline:
- **`validateWriterOutput` (Validator 1):**
  - Asserts non-empty `title`, `summary`, and deduplicated lowercase `tags`.
  - Validates character names are unique, non-empty, and none named `"Narrator"`.
  - Asserts turn count `>= 2`.
  - Normalizes speakers against canonical character names, rejecting unknown speakers with structured `ValidationError`.
  - Strips premature `<...>` tags from Writer output.
  - Automatically splits turns with text length `> 600` characters at sentence boundaries (`. `, `! `, `? `).
  - Renumbers `turn_id` strictly 1 to N.
- **`validateDirectorOutput` (Validator 2):**
  - Confirms turn count matches Writer turn count, preserving `turn_id` and `speaker`.
  - Sanitizes parenthetical stage cues (e.g., `(whispering)`) introduced by the Director by extracting them into `turn.style` and stripping them from `turn.text`.
  - Whitelists and normalizes vocal tags to lowercase, stripping unauthorized tags (e.g., `<explosion>`).
  - Audits word integrity: if the Director mutated story prose, restores Writer words while preserving valid vocal tags.
  - Ensures `turn.style` is non-empty (`<= 200` characters), falling back to `"Warm, gentle storytelling tone"`.
  - Validates `voice_candidates` array contains 1 to 3 valid entries.
